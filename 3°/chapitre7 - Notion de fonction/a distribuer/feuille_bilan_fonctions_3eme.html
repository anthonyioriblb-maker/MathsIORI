🔢 FEUILLE BILAN - NOTION DE FONCTION

Classe de 3ème

I. Définition et vocabulaire

Définition : Une fonction est un procédé qui, à un nombre, associe un unique autre nombre.

Vocabulaire important :

  • Le nombre de départ s'appelle l'antécédent (ou la variable)
  • Le nombre d'arrivée s'appelle l'image
  • On note souvent la fonction f et l'antécédent 𝑥
  • L'image de 𝑥 par 𝑓 se note : 𝑓(𝑥) (se lit "f de x")
Exemple : La fonction 𝑓 qui à un nombre associe son double.
• Si 𝑥 = 3, alors 𝑓(3) = 6
• Si 𝑥 = -5, alors 𝑓(-5) = -10
→ On dit que 6 est l'image de 3 par 𝑓 et que 3 est un antécédent de 6 par 𝑓
Un nombre a une seule image, mais une image peut avoir plusieurs antécédents !

II. Représentations d'une fonction

1) Par une expression algébrique

Exemples :
• 𝑓(𝑥) = 2𝑥 + 3
• 𝑔(𝑥) = 𝑥² - 4
• ℎ(𝑥) = -3𝑥² + 5

2) Par un tableau de valeurs

Exemple : Tableau de valeurs pour 𝑓(𝑥) = 𝑥² - 4
𝑥 -2 -1 0 1 2
𝑓(𝑥) 0 -3 -4 -3 0
Détail pour 𝑥 = -1 :
𝑓(-1) = (-1)² - 4 = 1 - 4 = -3

3) Par une courbe représentative

Propriété : Dans un repère, on peut représenter une fonction par une courbe.
Chaque point de la courbe a pour coordonnées (𝑥 ; 𝑓(𝑥))

III. Calculer une image

Méthode : Pour calculer l'image d'un nombre par une fonction :
On remplace 𝑥 par le nombre dans l'expression de la fonction.
Exemple 1 : Soit 𝑓(𝑥) = 3𝑥 - 5. Calculer 𝑓(-2).
Solution :
𝑓(-2) = 3 × (-2) - 5
𝑓(-2) = -6 - 5
𝑓(-2) = -11
→ L'image de -2 par 𝑓 est -11
Exemple 2 : Soit 𝑔(𝑥) = 2𝑥² + 3. Calculer 𝑔(-3).
Solution :
𝑔(-3) = 2 × (-3)² + 3
𝑔(-3) = 2 × 9 + 3
𝑔(-3) = 18 + 3
𝑔(-3) = 21
→ L'image de -3 par 𝑔 est 21
Exemple 3 : Soit ℎ(𝑥) = -x² + 4. Calculer ℎ(-2).
Solution :
ℎ(-2) = -(-2)² + 4
ℎ(-2) = -4 + 4
ℎ(-2) = 0
→ L'image de -2 par ℎ est 0

IV. Déterminer un antécédent

Méthode : Pour déterminer un antécédent d'un nombre b par une fonction 𝑓 :
On résout l'équation 𝑓(𝑥) = 𝑏
Exemple 1 : Soit 𝑓(𝑥) = 3𝑥 - 5. Déterminer l'antécédent de -8 par 𝑓.
Solution :
On cherche 𝑥 tel que 𝑓(𝑥) = -8
3𝑥 - 5 = -8
3𝑥 = -8 + 5
3𝑥 = -3
𝑥 = -33
𝑥 = -1
→ Un antécédent de -8 par 𝑓 est -1
Exemple 2 : Soit 𝑔(𝑥) = 𝑥² - 9. Déterminer les antécédents de 0 par 𝑔.
Solution :
On cherche 𝑥 tel que 𝑔(𝑥) = 0
𝑥² - 9 = 0
𝑥² = 9
𝑥 = 9 ou 𝑥 = -9
𝑥 = 3 ou 𝑥 = -3
→ Les antécédents de 0 par 𝑔 sont 3 et -3
Exemple 3 : Soit ℎ(𝑥) = 2𝑥² + 1. Déterminer les antécédents de 19 par ℎ.
Solution :
On cherche 𝑥 tel que ℎ(𝑥) = 19
2𝑥² + 1 = 19
2𝑥² = 19 - 1
2𝑥² = 18
𝑥² = 182
𝑥² = 9
𝑥 = 9 ou 𝑥 = -9
𝑥 = 3 ou 𝑥 = -3
→ Les antécédents de 19 par ℎ sont 3 et -3
Exemple 4 : Soit 𝑓(𝑥) = -x² + 5. Déterminer les antécédents de 1 par 𝑓.
Solution :
On cherche 𝑥 tel que 𝑓(𝑥) = 1
-x² + 5 = 1
-x² = 1 - 5
-x² = -4
𝑥² = -4-1
𝑥² = 4
𝑥 = 4 ou 𝑥 = -4
𝑥 = 2 ou 𝑥 = -2
→ Les antécédents de 1 par 𝑓 sont 2 et -2

V. Lecture graphique

Pour lire graphiquement :
• Une image : On part de l'antécédent sur l'axe des abscisses, on monte/descend jusqu'à la courbe, puis on lit l'ordonnée
• Un antécédent : On part de l'image sur l'axe des ordonnées, on va horizontalement jusqu'à la courbe, puis on lit l'abscisse

VI. À retenir absolument

  • 𝑓(𝑥) se lit "f de 𝑥" et non "f fois x"
  • Un antécédent peut ne pas exister
  • Une image existe toujours pour les fonctions usuelles
  • Un nombre a une seule image par une fonction donnée
  • Un nombre peut avoir plusieurs antécédents (surtout avec 𝑥²)
  • Avec 𝑥² : attention au signe ! (-3)² = 9
  • Pour les antécédents : bien vérifier les deux solutions possibles avec 𝑥²
  • Image = ordonnée du point / Antécédent = abscisse du point

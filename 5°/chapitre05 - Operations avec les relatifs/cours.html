Chapitre 5 : Calculs avec les nombres relatifs

Addition de nombres relatifs

💡 Méthode : Pour additionner deux nombres relatifs, on commence par regarder s'ils ont le même signe ou s'ils sont de signes différents.

Même signe

Propriété : Pour additionner deux nombres relatifs de même signe :
  • On additionne les distances à zéro des deux nombres ;
  • On prend le signe des deux nombres.
Exemples :
A = ( +2 ) + ( +5 )
A = +7
B = ( −2 ) + ( −5 )
B = −7
C = ( +3,5 ) + ( +1,2 )
C = +4,7
D = ( −8,4 ) + ( −0,7 )
D = −9,1

Signes contraires

Propriété : Pour additionner deux nombres relatifs de signes contraires :
  • On prend le signe du nombre qui a la plus grande distance à zéro ;
  • On soustrait les distances à zéro.
Exemples :
E = ( −2 ) + ( +6 )
E = +4
F = ( −5 ) + ( +2 )
F = −3
G = ( +4,5 ) + ( −11 )
G = −6,5
H = ( +8,3 ) + ( −2,9 )
H = +5,4

Opposé d'un nombre relatif

Définition : L'opposé d'un nombre relatif est le nombre qui a la même distance à zéro mais le signe contraire.
Exemples :
L'opposé de +3 est −3
L'opposé de −7 est +7
L'opposé de +4,6 est −4,6
L'opposé de −0,5 est +0,5
💡 Remarque : La somme d'un nombre et de son opposé est toujours égale à 0.
Exemple : ( +3 ) + ( −3 ) = 0

Soustraction de nombres relatifs

Propriété : Soustraire un nombre, c'est ajouter son opposé.
Exemples :
I = ( +2 ) − ( +3 )
I = ( +2 ) + ( −3 )
I = −1
J = ( +2,5 ) − ( −3 )
J = ( +2,5 ) + ( +3 )
J = +5,5
K = ( −5 ) − ( +8,2 )
K = ( −5 ) + ( −8,2 )
K = −13,2
L = ( −1,5 ) − ( −4 )
L = ( −1,5 ) + ( +4 )
L = +2,5

Enchaînement d'opérations

Méthode : Pour calculer une expression avec plusieurs additions et soustractions de relatifs, on suit les étapes suivantes :
  • Étape 1 : On transforme toutes les soustractions en additions de l'opposé ;
  • Étape 2 : On élimine les paires de nombres opposés s'il y en a ;
  • Étape 3 : On regroupe les termes positifs ensemble et les termes négatifs ensemble ;
  • Étape 4 : On additionne les termes positifs d'un côté, les termes négatifs de l'autre ;
  • Étape 5 : On effectue le dernier calcul.
Exemple : On veut calculer l'expression :

M = ( −6 ) + ( +2 ) − ( −4 ) + ( +5 ) + ( −2 ) − ( +11 )
Étape 1 : On transforme les soustractions en additions
M = ( −6 ) + ( +2 ) + ( +4 ) + ( +5 ) + ( −2 ) + ( −11 )

Étape 2 : On élimine les opposées s'il y en a
M = ( −6 ) + ( +2 ) + ( +4 ) + ( +5 ) + ( −2 ) + ( −11 )
M = ( −6 ) + ( +4 ) + ( +5 ) + ( −11 )

Étape 3 : On regroupe les termes positifs et les termes négatifs
M = ( +4 ) + ( +5 ) + ( −6 ) + ( −11 )

Étape 4 : On additionne chaque groupe
M = ( +9 ) + ( −17 )

Étape 5 : On effectue le dernier calcul
M = −8

Écriture simplifiée d'une somme

Propriété : Une fois les soustractions transformées en additions, on peut supprimer les parenthèses inutiles, mais deux signes ne doivent jamais se suivre.
  • Un nombre positif s'écrit sans parenthèses et sans son signe + : + ( +5 ) s'écrit + 5 ;
  • la somme avec un nombre négatif s'écrit comme une différence : + ( −3 ) s'écrit − 3 ;
  • au début du calcul, ( −6 ) s'écrit −6 et ( +6 ) s'écrit 6 ;
  • les parenthèses sont indispensables autour d'un nombre négatif placé juste après un signe d'opération : 8 − ( −2 ) ne peut pas s'écrire 8 − −2.
Exemples :
N = ( +5 ) + ( −3 )
N = 5 − 3
N = 2
P = ( −2 ) + ( +9 )
P = −2 + 9
P = 7
Q = ( −4,5 ) + ( −1 )
Q = −4,5 − 1
Q = −5,5
R = ( +7 ) − ( −2 )
R = ( +7 ) + ( +2 )
R = 7 + 2
R = 9
Exemple : On reprend le calcul de M (partie IV) avec l'écriture simplifiée.
M = ( −6 ) + ( +2 ) − ( −4 ) + ( +5 ) + ( −2 ) − ( +11 )
M = ( −6 ) + ( +2 ) + ( +4 ) + ( +5 ) + ( −2 ) + ( −11 )
M = −6 + 2 + 4 + 5 − 2 − 11
M = −6 + 4 + 5 − 11
M = 4 + 5 − 6 − 11
M = 9 − 17
M = −8

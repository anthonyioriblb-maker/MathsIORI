Dessin mystère

Clique sur les nœuds du quadrillage pour tracer les contours. La fiche se construit toute seule.

Tracé

Cliquer sur le premier point d’une série la ferme. Clic droit sur un point = le supprimer. Ctrl+Z = annuler.
